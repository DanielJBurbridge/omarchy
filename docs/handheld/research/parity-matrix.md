# Parity matrix: ROG Ally RC71L (Z1 Extreme), Bazzite vs CachyOS Handheld vs SteamOS vs Omarchy

Researched 12 Nov 2026 (AWST). Sources are inline. **Unverified** = no primary source found. Device state comes from `ally-hw-dump.md`: kernel 7.2.15-2-omarchy, `asus_armoury` loaded, `asusd` and `power-profiles-daemon` running, InputPlumber and steamos-manager not installed, and the MCU-firmware-below-319 warning.

**steamos-manager is a recommendation, not a decision. An earlier independent review rejected stock steamos-manager 26.4.1-3 even when inactive, and it is being re-assessed.**

## Recommended stack (10 lines)
1. Input: `extra/inputplumber` (0.84.0, GPL-3.0-or-later) with Omarchy's RC71L composite config and profiles. Not HHD (Bazzite, its last major user, has left it).
2. Paddles/RGB: need the out-of-tree `hid-asus-ally`. Offer the opt-in `linux-cachyos-deckify` kernel, or a DKMS/hidraw shim on the stock Omarchy kernel.
3. Steam TDP slider: `steamos-manager` (MIT; CachyOS repo only, build from gitlab.steamos.cloud). It already knows RC71L and drives `asus-armoury` PPT + `platform_profile`.
4. Power arbitration: in gaming mode on a detected RC71L only, steamos-manager owns TDP/profile. Stop or mask `power-profiles-daemon`, and stop `asusd` from touching profile/PPT, then restore both on desktop. Do not mask `power-profiles-daemon` on laptops. RC71L skips asusctl anyway. Never run PowerStation or HHD alongside.
5. Session: gamescope + Steam via CachyOS `gamescope-session-cachyos` (MIT) patterns: a gamescope session, `steamos-session-select` and a "Return to Gaming Mode" entry. Hyprland is the desktop. The CachyOS pkexec `steam-set-session` path that rewrites display-manager autologin conflicts with spec 02 and must not ship without review (recommendation 4).
6. Power button: `steamos-powerbuttond` (BSD-2-Clause, AUR/CachyOS) in gaming mode. Omarchy already tags `STEAMOS_POWER_BUTTON`.
7. Fan: firmware curves only. `asus-wmi` custom fan curves fail on this unit (-19) and no stack offers RC71L curves without HHD.
8. OSK: Steam OSK in gaming mode, wvkbd on Hyprland (AUR). Overlay: Steam QAM. OGUI is optional and later.
9. Kernel floor: ≥6.19 for `asus-armoury` (PPT via firmware-attributes). Ally keycodes need ≥6.10. Update the MCU to ≥319 before debugging suspend.
10. CachyOS-Handheld RC71L PipeWire filter-chain + WirePlumber configs, logind `HandlePowerKey=ignore` and hid preload are GPL-3.0-or-later. Reimplement from behaviour, or vendor them as separately-licensed files with LICENSE and SPDX headers. Decision for Daniel. Session-select scripts are covered in recommendation 4.

## Prioritised recommendations
1. **Ship InputPlumber (`extra`) and steamos-manager together as "gaming mode".** On a detected RC71L only, add a systemd `Conflicts=` or explicit stop of `power-profiles-daemon`, `asusd`, `hhd*`, `powerstation` while gaming mode is active (Omarchy `power.py` already lists these as conflicts). Restore them on desktop. Do not mask `power-profiles-daemon` on laptops. Keeping SOM in both modes and dropping ppd is an RC71L-only alternative.
2. **Package steamos-manager for Omarchy** from the CachyOS PKGBUILD (MIT). Pin it to a tag. Talk to the session D-Bus `com.steampowered.SteamOSManager1` (Omarchy `power.py` already does).
3. **Decide the kernel story for paddles/RGB** (`linux-cachyos-deckify` opt-in vs DKMS vs hidraw shim).
4. **Session plumbing:** a gamescope session, `steamos-session-select` → Hyprland, and a "Return to Gaming Mode" desktop entry. Reusing CachyOS `steam-set-session` and its polkit policy (pkexec writes the autologin config under `/etc`) conflicts with spec 02, which chose user-state switching and does not edit SDDM configuration (`docs/rog-ally-gaming-session.md` on `feat/ally-session-20261111`). A polkit rule that lets the session user rewrite display-manager autologin without authentication is a privilege surface. Do not ship that path without review.
5. **Resume hook** that re-applies TDP (mitigates SteamOS #2790-class bugs). Ask Daniel to update the MCU to ≥319.
6. **CachyOS RC71L audio configs** (GPL-3.0-or-later): reimplement from behaviour, or vendor as separately-licensed files with LICENSE and SPDX headers. Decision for Daniel. Omarchy is MIT. Attribution alone does not cover copying these files in.
7. Defer fan curves, OGUI, dock auto-switch and Decky.
