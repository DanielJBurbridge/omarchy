## How to read a row

Distro columns: **BZ** Bazzite Deck images, **CH** CachyOS Handheld, **SO** SteamOS 3.8.10 (notes of 17 Jun 2026). Cells are **Y** (documented user-facing behaviour), **P** (optional, device-limited, or only partly there), **N** (not found in the sources read), **?** (unverified).

**Integ** is source on this branch:

- **have** — the behaviour is implemented here. Still unproven on the RC71L unless a note says otherwise.
- **partial** — a piece is in the tree, or the desktop has it and gaming mode does not.
- **missing** — no implementation in this tree.

**Effort** is S (a package dependency or a small profile), M (one new command or service), L (a new surface, a kernel driver, or a trusted auth UI).

**Upstream** is whether the change belongs in Omarchy:

- **yes** — Omarchy core. It helps a normal desktop as well as the Ally.
- **maybe** — an opt-in handheld package, gated on `omarchy-hw-rog-ally`, not the laptop default.
- **no** — do not put it in core, and do not copy it into this MIT tree. A separate package with its own licence is the only reuse, or the design is already rejected.

Omarchy's licence file is the MIT text ([LICENSE](../../../LICENSE)). GPL and LGPL code stays in its own package. A repository with no licence is ideas only. That rule is already in this directory's [README](README.md).

## What this branch already runs

The gaming session is real code, not only a spec. [`bin/omarchy-session-start`](../../../bin/omarchy-session-start) launches `gamescope --backend drm -e --xwayland-count 2 --default-touch-mode 4` and Steam. [`bin/omarchy-gaming-steam`](../../../bin/omarchy-gaming-steam) runs `steam -steamos3 -steampal -steamdeck -gamepadui`. The comment above that line says the script does not set fake Deck flags for HDR, fan, TDP, drive formatting or OS update. Steam's own QAM can still draw. The hardware sliders inside it stay hidden until something answers Steam's manager API. That is the backlog in [parity-matrix.md](parity-matrix.md): a small root writer for power limits, and a session-bus shim for the public `SteamOSManager1` API. Stock steamos-manager stays out.

The same launcher already looks for optional companions and skips them when they are absent: `omarchy-display-rog-ally`, `mangoapp`, `omarchy-rog-ally-input`, `steamos-manager.service`, `omarchy-ally-power.service`, `omarchy-ally-tdp-shim.service`, and `steamos-powerbuttond`. The drop-ins that would bind the input bridge and the TDP shim to the gaming target are in the tree. The units they bind are not. [`docs/handheld/ALPHA.md`](../ALPHA.md) still lists the Switch to Gaming row as missing. The row is in [`default/omarchy/omarchy-menu.jsonc`](../../../default/omarchy/omarchy-menu.jsonc) and `Super+Ctrl+G` is in [`default/hypr/bindings/utilities.lua`](../../../default/hypr/bindings/utilities.lua).

The only Ally boot recorded for this line came up on the desktop, with Wi-Fi off. That result is in [HANDOVER.md](../HANDOVER.md). It was integ `d3747faf`, which is behind this tip.

## Ranked gaps

Impact first, then effort. Boot and "can I use it in my hands" come before overlays and RGB. "Have" rows above are not gaps.

1. **Autologin that SDDM will honour.** The drop-in sets the session and `Relogin` and leaves `User=` out. The provisioner writes `User=` into a different file and an unencrypted install deletes that file. Effort S. This is why a handheld can boot to the greeter or the desktop. [touch-first-boot.md](touch-first-boot.md), [`bin/omarchy-handheld-autologin`](../../../bin/omarchy-handheld-autologin).
2. **Shift and symbols on the greeter keypad.** Backspace, space and enter are in [`default/sddm/omarchy/Main.qml`](../../../default/sddm/omarchy/Main.qml), and enter calls `sddm.login` ([ALPHA.md](../ALPHA.md)). A password with a capital or a symbol still has no key, so that password still needs a USB keyboard. Effort M, and it stays the trusted login UI.
3. **InputPlumber installed, with a gaming profile and a desktop profile.** Until that exists, QAM, the Steam menu, the OSK chord, paddles and sticks-as-mouse are all the same gap. Effort M. Depend on `extra/inputplumber`. Write new YAML. The profiles, the D-Bus load and the licence split are [inputplumber-profiles-brief.md](inputplumber-profiles-brief.md). [buttons-and-input.md](buttons-and-input.md).
4. **TDP, AC/battery limits, charge limit, and a resume reapply.** The session already restarts a shim that is not in the tree. Stock steamos-manager stays rejected. Effort L. Opt-in package. [parity-matrix.md](parity-matrix.md), [SteamOS #2790](https://github.com/ValveSoftware/SteamOS/issues/2790).
5. **Ally speaker DSP.** Bazzite calls the audio soft, and the volumes of the two devices are linked. CachyOS ships a filter. The files have no licence. Effort M. Reimplement in an opt-in package. [ASUS page](https://docs.bazzite.gg/Handheld_and_HTPC_edition/Handheld_Wiki/ASUS_ROG_Ally/).
6. **Gaming-mode power button.** The launcher and the udev tag exist. `steamos-powerbuttond` does not. Effort S. BSD-2-Clause companion. Desktop suspend already works, and it skips the lock until K07.
7. **Undocked touch desktop.** Gestures, a keyboard summon that works beside fcitx5, and larger menu targets. Effort M. The other three distros do not build this, because they stay in Steam. It is still the desktop you land on when gaming fails. Companion note.
8. **Paddles, stick-ring RGB, and vibration.** They need `hid-asus-ally`, which is GPL-2.0-or-later and out of tree. Effort L. Opt-in kernel. Do not paste the driver here. Gyro aiming is the same profile work as gap 3 once a Deck or DualSense target is selected, and it does not need that driver for the IMU itself.
9. **Dock picture and a deliberate session switch.** `omarchy-display-rog-ally` is absent. Automatic switch-on-dock is an Omarchy principle, not something Bazzite, CachyOS or SteamOS do. Effort M for the display helper, L for the switch. Spec 02.
10. **Game-mode Wi-Fi, Bluetooth, screenshots, and a way to run `omarchy update` from the pad.** Several of these may already work inside Steam and have not been tried (OQ-10). Effort S to test, M if Steam cannot see NetworkManager or BlueZ. Snapshots already exist for rollback. The missing piece is a controller path to them.

Lower, in order: mono audio and a high-contrast theme (core, S/M), VRR quirks copied as our own env (S, measure first), LAVD as a measured experiment (M), Decky and OGUI left out, fan curves left alone, MCU firmware left to the Windows tool after a backup. Update the MCU to at least 319 before debugging suspend.

## Surprises

- [ALPHA.md](../ALPHA.md) still says the Switch to Gaming row is missing. The row and `Super+Ctrl+G` are in this tree.
- The session looks more finished than the missing units suggest. It already calls display args, mangoapp, a power marker, the TDP shim and powerbuttond, and it no-ops when they are absent. Shipping the packages turns those hooks on. The hooks are not the features.
- [`bin/omarchy-gaming-steam`](../../../bin/omarchy-gaming-steam) passes `-steamos3 -steampal -steamdeck -gamepadui` and, in the comment above, refuses the fake Deck capability flags. Steam will show a handheld UI and hide TDP, fan, formatting and OS-update controls. That is a choice, not a bug in the launch line.
- Bazzite's Ally page still documents Armoury-hold as mouse mode, and the page says the wiki may be outdated. Deck 44's handheld wiki documents InputPlumber and OpenGamepadUI. Treat the mouse-mode sentence as the old HHD behaviour.
- CachyOS-Handheld and the `cachyos` branch of gamescope-session still have no GitHub licence. chwd does, and it is GPL-3.0-only. The audio files people want to copy are in the unlicensed repo.
- Dock-to-desktop is ours. The three distros were checked again. None of them switch session because a dock appeared.
- InputPlumber's stock "mouse" profile is a hybrid: right stick pointer, left stick WASD. The default profile does not map sticks to a pointer at all. See the companion note.
- The closest Omarchy tablet project with a real touch keyboard, [omarchy-osk](https://github.com/ekollof/omarchy-osk), is MIT and vendors hyprgrass. [omarchy-tablet](https://github.com/yeutterg/omarchy-tablet) has no licence file.
- This branch's launcher is the Quickshell menu. Walker is a word in spec 02. Fuzzel is not in the tree.
